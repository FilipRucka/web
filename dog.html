    1. Tournament Overview

    The goal was to train a quadruped to maximize forward distance within a 1000-step limit.

    2. Policy Architecture

    I implemented a custom actor-critic network using a Shared Backbone approach. The network processes the 29-dimensional state space through three linear layers (256 units), each stabilized by Layer Normalization and Tanh activations.

    Unlike standard Gaussian policies, I used a Beta Distribution for the action head. The network outputs shape parameters $\alpha$ and $\beta$, which are passed through a Softplus function and clamped. This ensures the agent's actions always stay within valid torque limits.

    3. Algorithm & Optimization

    The agent is trained using Proximal Policy Optimization (PPO). I chose PPO because it provides a stable balance between ease of tuning and performance. To improve the quality of the learning signal, I paired it with Generalized Advantage Estimation (GAE).

    Breaking Correlations (Mini-Batching)

    Reinforcement learning data is naturally time-correlated (state $t$ is very similar to state $t+1$). To prevent the optimizer from overfitting to specific trajectories, I implemented a shuffling mechanism. Collected trajectories are flattened and randomized into mini-batches (size 4096), breaking these correlations and ensuring the neural network learns generalizable features rather than memorizing a specific sequence.

    Stabilizing Updates

    A key optimization in my code is Advantage Normalization. Before every update, I rescale the calculated advantages to have zero mean and unit variance. This simple step ensures that the training remains stable regardless of the scale of the rewards, allowing the agent to learn consistently whether it's receiving small penalties or massive velocity bonuses.

    4. Reward Engineering

    The reward function in `walker_reward` solves the multi-objective problem of speed versus stability:

    • Exponential Velocity Incentive: Forward velocity ($v_x$) is rewarded using a power of 1.5 ($v_x^{1.5}$). This makes the reward non-linear: doubling your speed more than doubles your reward, aggressively encouraging sprinting.
    • Threshold Boost: To break local optima, I added a "fast bonus" that only triggers when velocity exceeds 4.2 m/s. This creates a strong gradient pushing the agent toward top speeds.
    • Stability Constraints: Penalties are applied to vertical velocity ($v_z^2$) and lateral drift ($v_y^2$) to force an energy-efficient, planar gait.

    5. Full Implementation

    The implementation is split into the neural network architecture (Beta Policy) and the training pipeline (PPO + GAE).

                import torch
                import torch.nn as nn
                import torch.nn.functional as F
                import numpy as np
                
                class WalkerPolicy(nn.Module):
                    def __init__(self, state_dim=29, action_dim=8, load_weights: bool = False):
                        super().__init__()
                        
                        self.net = nn.Sequential(
                            nn.Linear(state_dim, 256),
                            nn.LayerNorm(256),
                            nn.Tanh(),
                            nn.Linear(256, 256),
                            nn.LayerNorm(256),
                            nn.Tanh(),
                            nn.Linear(256, 256), 
                            nn.LayerNorm(256),
                            nn.Tanh()
                        )
                        
                        self.action_head = nn.Linear(256, 2 * action_dim)
                        self.actor_logstd = nn.Parameter(torch.zeros(1, action_dim)) 
                
                        self.critic = nn.Sequential(
                            nn.Linear(state_dim, 256),
                            nn.LayerNorm(256),
                            nn.Tanh(),
                            nn.Linear(256, 256),
                            nn.LayerNorm(256),
                            nn.Tanh(),
                            nn.Linear(256, 1)
                        )
                        
                        self.apply(self._init_weights)
                        nn.init.orthogonal_(self.action_head.weight, gain=0.01)
                        nn.init.constant_(self.action_head.bias, 0)
                
                        if load_weights:
                            self.load_weights()
                        
                    def _init_weights(self, module):
                        if isinstance(module, nn.Linear):
                            nn.init.orthogonal_(module.weight, gain=np.sqrt(2))
                            if module.bias is not None:
                                nn.init.constant_(module.bias, 0)
                    
                    def forward(self, state):
                        if isinstance(state, np.ndarray):
                            state = torch.from_numpy(state).float()
                            
                        x = self.net(state)
                        out = self.action_head(x)
                        
                        alpha_raw, beta_raw = torch.chunk(out, 2, dim=-1)
                        
                        alpha = F.softplus(alpha_raw).clamp(max=200.0) + 1.0
                        beta = F.softplus(beta_raw).clamp(max=200.0) + 1.0
                        
                        return alpha, beta
                
                    def get_value(self, state):
                        if isinstance(state, np.ndarray):
                            state = torch.from_numpy(state).float()
                        return self.critic(state)
                        
                    def act(self, state):
                        """
                        Sample an action for training/exploration.
                        """
                        with torch.no_grad():
                            alpha, beta = self.forward(state)
                            dist = torch.distributions.Beta(alpha, beta)
                            action_01 = dist.sample()
                            # Scale [0, 1] -> [-1, 1]
                            action = action_01 * 2.0 - 1.0
                        return action.numpy()
                    
                    def determine_actions(self, state: torch.Tensor) -> torch.Tensor:
                        """
                        Deterministic action for evaluation (Mode of the distribution).
                        Means = Alpha / (Alpha + Beta)
                        """
                        self.eval() 
                        with torch.no_grad():
                            if isinstance(state, np.ndarray):
                                state = torch.from_numpy(state).float()
                                
                            alpha, beta = self.forward(state)
                            action_01 = alpha / (alpha + beta)
                            actions = action_01 * 2.0 - 1.0
                            
                        return actions
                
                    def save_weights(self, path: str = 'walker_weights.pt') -> None:
                        torch.save(self.state_dict(), path)
                
                    def load_weights(self, path: str = 'walker_weights.pt') -> None:
                        try:
                            self.load_state_dict(torch.load(path, map_location=torch.device('cpu')))
                            print(f"Loaded weights from {path}")
                        except FileNotFoundError:
                            print(f"Warning: Could not find weight file {path}")

                import torch
                import torch.optim as optim
                import torch.nn as nn
                import torch.nn.functional as F

                def compute_gae(rewards, values, next_val, dones, gamma, lam):
                    """
                    Computes Generalized Advantage Estimation (GAE).
                    """
                    advantages = np.zeros_like(rewards, dtype=np.float32)
                    last_gae_lam = 0
                    
                    for t in reversed(range(len(rewards))):
                        if t == len(rewards) - 1:
                            next_v = next_val
                        else:
                            next_v = values[t + 1]
                            
                        mask = 1.0 - dones[t]
                        delta = rewards[t] + (gamma * next_v * mask) - values[t]
                        advantages[t] = last_gae_lam = delta + (gamma * lam * mask * last_gae_lam)
                        
                    return torch.tensor(advantages, dtype=torch.float32)
                
                def ppo_loss(p_ratios, advantage_estimates, epsilon):
                    surr1 = p_ratios * advantage_estimates
                    surr2 = torch.clamp(p_ratios, 1.0 - epsilon, 1.0 + epsilon) * advantage_estimates
                    return -torch.mean(torch.min(surr1, surr2))
                
                def value_loss(values, value_targets):
                    return torch.mean((values - value_targets)**2)
                
                print("\nTraining: PRO MODE (Self-Contained)")
                
                best = {
                    'lr': 0.000005,           
                    'gamma': 0.99,
                    'clip_ratio': 0.15,      
                    'train_iters': 10,       
                    'batch_size': 4096,      
                    'entropy_coef': 0.01     
                }
                
                MAX_EPOCHS = 15000 
                STEPS_PER_EPOCH = 16384 
                CURRICULUM = {
                    "target_vx": 16.0,       
                    "pen_z_weight":  0.1612,

                best_single_run_record = -float('inf')

                    TARGET_VX = CURRICULUM["target_vx"]

                    vx = state[15]

                    v_error = TARGET_VX - vx
                    rew_forward = 18 * vx

                    rew_healthy = 0.1 * is_healthy
                    pen_z_vel = CURRICULUM["pen_z_weight"] * vz**2

                    # --- TOTAL ---
                    total_reward = (

                            obs_t = torch.FloatTensor(obs)
                            alpha, beta = final_policy(obs_t)

                            action_01 = dist.sample()
                            vx = torch.from_numpy(obs[:, 15]).float()
                            log_prob = dist.log_prob(action_01).sum(axis=-1)
                            val = final_policy.get_value(obs_t).squeeze()
                        
                        action_env = action_01.numpy() * 2.0 - 1.0
                        next_obs, reward = env.vector_step(action_env)
                        
                        current_x = next_obs[:, 0]
                        dx = current_x - previous_x
                        dx[dx < -0.5] = 0.0 
                        current_episode_dists += dx
                        previous_x = current_x.copy()
                        
                        is_flipped = (next_obs[:, 4]**2 + next_obs[:, 5]**2) > 0.6
                        dones = is_flipped.astype(float)
                
                        for i in range(num_envs):
                            if is_flipped[i] or t == STEPS_PER_BATCH - 1:
                                if current_episode_dists[i] > max_episode_dist_in_epoch:
                                    max_episode_dist_in_epoch = current_episode_dists[i]
                                if is_flipped[i]:
                                    current_episode_dists[i] = 0.0
                
                        b_obs.append(obs); b_acts.append(action_01); b_rews.append(reward)
                        b_dones.append(dones); b_vals.append(val); b_logp.append(log_prob)
                        obs = next_obs
                
                    t_obs = torch.tensor(np.array(b_obs), dtype=torch.float32) 
                    t_acts = torch.stack(b_acts)                               
                    t_rews = torch.tensor(np.array(b_rews), dtype=torch.float32)
                    t_dones = torch.tensor(np.array(b_dones), dtype=torch.float32)
                    t_vals = torch.stack(b_vals)                              
                    t_logp = torch.stack(b_logp)                              
                
                    with torch.no_grad():
                        last_val = final_policy.get_value(torch.FloatTensor(obs)).squeeze() 
                
                    t_obs = t_obs.permute(1, 0, 2)   
                    t_acts = t_acts.permute(1, 0, 2)
                    t_rews = t_rews.permute(1, 0)   
                    t_dones = t_dones.permute(1, 0) 
                    t_vals = t_vals.permute(1, 0)    
                    t_logp = t_logp.permute(1, 0)   
                    
                    adv_list = []
                    ret_list = []
                    
                    for i in range(num_envs):
                        adv = compute_gae(
                            t_rews[i].numpy(), 
                            t_vals[i].numpy(), 
                            last_val[i].item(), 
                            t_dones[i].numpy(), 
                            best['gamma'], 
                            0.95 
                        )
                        adv_list.append(adv)
                        ret_list.append(adv + t_vals[i])
                
                    t_adv = torch.stack(adv_list)
                    t_ret = torch.stack(ret_list)
                
                    full_obs = t_obs.reshape(-1, 29)
                    full_acts = t_acts.reshape(-1, 8)
                    full_logp = t_logp.reshape(-1)
                    full_adv = t_adv.reshape(-1)
                    full_ret = t_ret.reshape(-1)
                
                    full_adv = (full_adv - full_adv.mean()) / (full_adv.std() + 1e-8)
                
                    total_samples = full_obs.shape[0] 
                    indices = np.arange(total_samples)
                    batch_size = best['batch_size']   
                
                    for _ in range(best['train_iters']):
                        np.random.shuffle(indices) 
                        for start_idx in range(0, total_samples, batch_size):
                            end_idx = start_idx + batch_size
                            mb_idxs = indices[start_idx:end_idx]
                
                            mb_obs = full_obs[mb_idxs]
                            mb_acts = full_acts[mb_idxs]
                            mb_logp_old = full_logp[mb_idxs]
                            mb_adv = full_adv[mb_idxs]
                            mb_ret = full_ret[mb_idxs]
                
                            optimizer.zero_grad()
                            alpha, beta = final_policy(mb_obs)
                            dist = torch.distributions.Beta(alpha, beta)
                            
                            new_log_p = dist.log_prob(mb_acts).sum(axis=-1)
                            ratio = torch.exp(new_log_p - mb_logp_old)
                            
                            loss_pi = ppo_loss(ratio, mb_adv, epsilon=best['clip_ratio'])
                            v_pred = final_policy.get_value(mb_obs).squeeze()
                            loss_v = value_loss(v_pred, mb_ret)
                            
                            entropy = dist.entropy().mean()
                            loss = loss_pi + 0.5 * loss_v - best['entropy_coef'] * entropy
                            
                            loss.backward()
                            torch.nn.utils.clip_grad_norm_(final_policy.parameters(), 0.5)
                            optimizer.step()
                            scheduler.step()
                   
                    print("cur run: {:.2f}m | epoch: {}/{}".format(
                        max_episode_dist_in_epoch, epoch + 1, MAX_EPOCHS))
                    if max_episode_dist_in_epoch > best_single_run_record:
                        best_single_run_record = max_episode_dist_in_epoch
                        print(f"NEW RECORD: {best_single_run_record:.2f}m")
                        torch.save(final_policy.state_dict(), f"ggs/policy.pth")
