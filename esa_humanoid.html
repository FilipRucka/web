Technical Walkthrough

In lunar teleoperation, a 2.6 s round-trip communication delay makes direct manual control slow and error-prone because the operator has to wait nearly three seconds to see the result of every movement. Built around the research focus of ESA's EAC Robotics & IoT Lab, this project tests how predictive visual feedback and robot-side local alignment improve sample-canister grasping, bench transfer, and cradle docking under a 1.3 s one-way delay.

The platform is a simulated Unitree G1 humanoid (29-DoF body plus an articulated 7-DoF right hand) in MuJoCo. The pelvis is fixed as a deliberate first scope so whole-body walking balance does not confound manipulation accuracy or latency measurements.

1. Architecture & Frame Calibration

The operator interface and the MuJoCo physics simulation run as separate UDP processes so ground-truth robot state never leaks into the operator's screen. Physics steps at 500 Hz, inverse kinematics and joint servos run at 100 Hz, and command/telemetry streams run at 30 Hz.

Denoting the robot-base, operator, controller, and end-effector frames by \(R\), \(O\), \(C\), and \(E\), re-indexing records the relative offset between the input controller and the robot hand. This lets the operator recenter their workspace at any time without causing a sudden jump in the robot's target:

\[T_{R,O} = T_{R,E}(0)\left[T_{O,C}(0)\right]^{-1}, \qquad T_{R,E}^* = T_{R,O}T_{O,C}\]

The interface accepts either desktop controls or live 6-DoF XR controller poses through the same \(T_{O,C}\) transform, smoothed with an exponential filter (\(\alpha = 1 - e^{-\Delta t / \tau}\), \(\tau = 0.10\,\mathrm{s}\)).

2. Constrained Upper-Body IK

At 100 Hz, the controller solves across 8 degrees of freedom (seven right-arm joints plus waist pitch) using weighted damped least squares with a null-space joint-limit barrier:

\[\dot{q} = J^T\left(JJ^T + \lambda^2 I\right)^{-1}e + \left(I - J^+J\right)g_{\mathrm{limit}}\]

The error vector \(e\) combines Cartesian position, weighted quaternion orientation, and a reach-dependent waist posture objective. For nearby targets, the arm moves alone to keep the torso steady; for distant reaches, the solver smoothly introduces a forward waist lean capped around \(27^\circ\). Joint limits, velocity caps, workspace bounds, and an elbow/bench height barrier prevent self-collision and table scraping before MuJoCo's contact solver takes over.

3. Delay & Predictive Feedback

A C++17 packet scheduler buffers timestamped UDP commands by \(1.3\,\mathrm{s}\), discards out-of-order packets, and runs a safety watchdog that freezes the arm if incoming commands stop for \(0.45\,\mathrm{s}\).

To eliminate blind move-and-wait behavior across the \(2.6\,\mathrm{s}\) round-trip loop, the operator view renders a real-time cyan ghost marker showing where the end-effector is predicted to be right now. Crucially, the predictor never accesses true simulator state—it rebases strictly on incoming delayed telemetry and integrates unacknowledged commands forward with a first-order response model and quaternion interpolation:

\[\hat{x}(t + \Delta t) = \hat{x}(t) + \left(1 - e^{-\Delta t / \tau_p}\right)\left(x_{\mathrm{cmd}} - \hat{x}(t)\right)\]

Because the cyan marker responds immediately to operator commands while staying anchored to real delayed telemetry, the operator can guide the hand continuously without waiting for the video feed to catch up. Physical actuation remains driven solely by the delayed command queue.

4. Local Alignment & Grasping

Predictive display feedback speeds up coarse motion, but small overshoots or prediction errors still make tight docking difficult when every correction takes \(2.6\,\mathrm{s}\) to travel back and forth. To solve this, I added a robot-side alignment assist that closes the fine positioning loop locally: once the closed hand carrying the canister enters a \(20\,\mathrm{cm}\) capture radius around the cradle, the controller blends in a bounded position correction toward the docking pose without waiting for operator input.

Instead of substituting a simplified parallel jaw, the simulation keeps the Unitree G1's articulated 7-DoF right hand. IK, prediction, and grasping all share a single palm-center frame so finger motion never shifts the predicted target. Closing the hand curls the thumb, index, and middle fingers over \(0.45\,\mathrm{s}\) onto a grasp latch; opening releases the canister so it drops and settles into the cradle through normal MuJoCo contact physics.
