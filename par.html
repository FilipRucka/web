1. Project Overview

I am developing an autonomous exploration system that enables a mobile robot to navigate an unknown environment.

The core logic relies on Occupancy Grid Maps to model the environment probabilistically and a Frontier-Based Exploration strategy to determine where to move next. The robot iteratively identifies frontiers and navigates to them until the entire reachable space is mapped.

2. Current Progress: Simulation

Currently, the algorithm is fully operational within the Gazebo simulation environment. The video below demonstrates the robot's ability to process laser scan data, update the occupancy grid in real-time using Bayesian rule, and autonomously select goals to explore the labyrinth.
